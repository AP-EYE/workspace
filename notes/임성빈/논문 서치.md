# 논문 서치

**Automated & Real-Time Privacy Quantification for Microservices Architectures**
- **발행처:** SciTePress (2025년 10월)
- **링크:** [https://www.scitepress.org/Papers/2026/151920/151920.pdf](https://www.scitepress.org/Papers/2026/151920/151920.pdf)
- **핵심 내용:** 마이크로서비스 환경에서 PII Score를 산출하여 운영 리스크를 실시간으로 정량화하는 모델 제시.
- **논문 활용 위치:** **\[개인정보 정량화 선행 연구\]** 파트에서 PII 노출 위험도를 수치화하려는 최신 연구 사례로 인용.

**CVSS v4.0 '환경/보완 메트릭(Environmental/Supplemental)'의 자동 계산 아키텍처**
- **최신(26년):** "최신 CVSS v4.0에 존재하는 '환경 점수(EQ)'와 '안전성/복구력 메트릭'을 API PII 노출 수준에 맞춰 **자동으로 계산(Automated Calculation)해주는 프레임워크**" 연구가 주류로 떠올랐습니다.
- **적용:** 우리 논문의 스코어링 수식을 단순히 독자적인 점수가 아니라, "CVSS v4.0 프레임워크에 PII 보호 상태(FPE 적용 여부 등)를 동적으로 매핑(Mapping)하는 확장 아키텍처"로 명명하면 학술적 가치가 극대화됩니다.

**LLM 기반 API 응답 문맥(Context) 분석 및 PII 동적 스코어링**
- **최신(26년):** 대형언어모델(LLM)을 활용해 API 응답(JSON/GraphQL) 데이터의 스키마를 분석하고, 이것이 실제 민감한 평문 데이터인지, 아니면 형태보존암호(NIST FPE)나 마스킹이 적용된 무의미한 데이터인지 문맥적으로 추론(Context-aware Inference)하여 위험도를 조정하는 연구가 폭발적으로 증가했습니다.
- **적용:** 우리 다이어그램 내부에 '영향도 산정 모듈'의 핵심 엔진으로 **'문맥 인식형 보호 상태 검증(Context-aware Protection State Validation)'** 계층을 추가하면 완벽한 26년도 트렌드가 됩니다.

**BOLA(API1)와 BOPLA(API3)의 체인(Chain) 공격 그래프 모델링**
- **최신(26년):** BOLA(객체 수준 권한 결함)를 통해 어떻게 BOPLA(과도한 데이터 노출)로 이어지는지, 그 공격의 사슬(Attack Graph/Kill Chain)을 추적하여 최종 데이터 유출 파급력을 스코어링하는 통합 연구가 메인스트림입니다.
