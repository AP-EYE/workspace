# 2026-10-06 조사 원자료 전체 보존

팀 공유용으로 편집한 [Akto 조사](../../akto/research-2026-10-06/README.ko.md)와 [태스크 2·4 보고서](../evaluation-datasets-2026-10-06/README.md)의 원자료 모음이다. 이 아카이브는 새로운 실험 결과를 추가하지 않는다.

## 범위

아래 로컬 조사 폴더의 연구 파일을 전수 대조하고, 파일별 원본 SHA-256과 브랜치 내 저장 위치를 [MANIFEST.json](MANIFEST.json)에 기록했다.

총 **648개 연구 파일**을 확인했다. **567개는 이 아카이브에 저장**했고 **81개는 내용이 동일한 저장 파일을 참조**한다. 외부 소스 사본 **16개**는 원격 주소·커밋·전체 파일 목록으로 고정했다.

- `local-materials/akto-research-2026-10-06/`: GitHub 이슈·PR 원문과 diff, 수집·색인·보고서 생성 스크립트, 원본 보고서, 컴포넌트 실행 결과, 참고 문헌·웹페이지.
- `local-materials/evaluation-datasets-2026-10-06/`: 초기 데이터셋 조사·실행·환경 증거와 스크립트.
- `local-materials/evaluation-review-2026-10-06/`: 추가 논문·PII 자료·원문 검토·wger 실행 및 경고 로그·검증 스크립트.

이전 조사·회의 자료는 기존 저장소 경로에 남아 있다. 이 범위와 무관한 Git 백업, 음성 출력, 킥오프 화면 추출 임시 파일은 이번 아카이브의 대상이 아니다.

## 저장 방식

이미 있는 결과물이나 다른 원자료와 바이트가 같으면 중복 복사 대신 해당 파일 위치를 연결했다. 그 밖의 파일은 `files/`에 원래 폴더 구조로 저장했다. 대용량 텍스트 원문은 `.gz`로 압축했으며, 압축 해제 후 내용의 SHA-256도 기록했다. 원본 수집 보고서의 당시 상태 설명·링크는 역사적 기록이며 최신 공유 경로는 위 팀 보고서를 따른다.

외부 저장소 사본은 원본 전체를 중복 업로드하는 대신 원격 주소, 정확한 커밋·Git tree, 전체 추적 파일 목록을 고정했다. 모든 사본의 작업 트리가 깨끗한지 확인했으며, 이 저장소의 코드와 조사자가 만든 연구 파일을 구분했다. 외부 소스는 해당 라이선스를 따른다.

외부 PR 테스트에 포함된 GitHub 토큰 형태의 예시 문자열은 `[REDACTED_TOKEN_EXAMPLE]`로 치환했다. 해당 파일은 원본 해시, 저장된 내용 해시, 치환 횟수를 모두 기록했다. 실제 자격정보인지 확인하려고 인증을 시도하지 않았다. 비밀키 헤더를 탐지하는 코드 문자열은 비밀키 본문이 아니므로 그대로 보존했다.

가상환경·캐시·`.git` 내부 상태는 연구 결과물이 아니므로 포함하지 않았다. 제외한 가상환경·캐시 디렉터리도 목록으로 기록했다. 원본 로컬 파일은 수정하지 않았다.

## 검증과 재구성

저장소 루트에서 모든 저장 파일과 압축 내용의 해시를 확인한다.

```powershell
python -X utf8 docs/research/raw-archive-2026-10-06/tools/archive.py verify
```

원본 로컬 조사 폴더도 있는 경우, 누락 여부와 원본 해시를 함께 검사한다.

```powershell
python -X utf8 docs/research/raw-archive-2026-10-06/tools/archive.py verify --workspace ..
```

`MANIFEST.json`의 각 `files` 항목은 `source`(원래 상대 경로), `storage`(저장소 내 실제 위치), `encoding`, 원본·저장 해시를 제공한다. `encoding: gzip`이면 일반 gzip 도구 또는 Python `gzip`으로 해제한다. 토큰 예시 치환 파일의 원본 바이트는 해시로만 기록하며 공개 아카이브로부터 복원하지 않는다.

외부 소스는 `source_repositories`의 `remote` 주소를 새 폴더에 clone하고 `commit`으로 checkout하면 된다. `source-trees/`에는 커밋의 모든 추적 파일 경로와 Git 객체 ID가 있다. 이 자료는 원본 소스 버전을 고정하는 용도이며 Akto의 전체 스캔이 실행됐다는 뜻은 아니다.
