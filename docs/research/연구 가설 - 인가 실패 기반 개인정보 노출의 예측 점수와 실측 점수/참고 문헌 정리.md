# 참고문헌 정리: 예측 점수 vs 실측 점수 가설

> 조사 방식 : 논문을 두 단계로 나눠 읽는다.
>
> - **1차 스크리닝**: 제목 → Abstract → Introduction → 결론만 보고 "무엇을 했고 무엇을 안 했는지"만 판단 (AI로 5~10분/편)
> - **2차 정독**: 1차에서 살릴 논문만 골라 연구 세부 질문·데이터셋·방법론·한계 확인
>
> 원칙: 모든 논문을 처음부터 끝까지 읽지 않는다. 넓게 훑어 분류하고, 가설과 직접 연결된 것만 정독한다.

## ✅ 2차 정독 완료 (원문 전체 확인)

| 논문 | 무엇을 했나 | 무엇을 안 했나 (우리 빈칸) |
| --- | --- | --- |
| **EDEFuzz** (ICSE 2024) | 응답 필드를 지워 UI 변화로 불필요 노출 필드 탐지. 참양성률 98.65% | 민감도·규모 점수화 없음. 인가 실패 대상 아님 |
| **AuthScope** (CCS 2017) | 재전송으로 인가 실패 597건 발견 | 규모를 앱 설치 수로만 어림. 예측 없음 |
| **AuthProbe** (2026) | 명세 기반 다중 계정 탐지, 값 반출 금지 | 고정 등급. 노출 내용·규모 미반영 |
| **WAScope** (2025) | mitmproxy 수집+재전송+개인정보 사전, 노출 API 2,757개 | 점수화 없음. 마스킹 272건을 오탐 처리 |
| **German Tank 추정** (통계) | 순차 번호로 전체 개수 N̂=m(1+1/k)−1 추정 | 보안·API 적용 사례 없음 (우리가 처음) |
| **ToolMinimize** (PST 2026) | 자동 점수화, 가중치 안정성 검증 | 필드 조합 효과 미모델링 (우리 I가 보완) |

## ⚠️ 2차 정독 필요 (1차만 완료 — 원문 세부 확인 예정)

| 논문 | 1차 판단 | 왜 2차가 필요한가 |
| --- | --- | --- |
| **L-Severity** (JCS 2016) | 점수 구조(민감도×식별성×규모)의 원조 | 식별성·규모 공식이 DB 전체 접근을 전제 → 블랙박스 API에서 어떻게 바꿔야 하는지 정확한 수식 확인 필수. **점수 설계 직결, 최우선** |
| **M-Score** (IEEE TDSC 2012) | L-Severity의 전신 | 식별성 정의가 우리 I와 얼마나 겹치는지 확인 |
| **Uniqueness ratio predictor** (arXiv 2601.11550, 2026) | 실행 전 예측→정답 대조. 단 DB 결합·방향 예측 | 예측-실측 대조 평가 설계를 우리 실험에 참고. 반례가 아니라 방법론 근거로 쓸 수 있는지 확인 |
| **SMS URL 연쇄 노출** (arXiv 2601.09232, 2026) | 규모 추정을 윤리 문제로 포기 | 규모 추정을 정확히 어느 지점에서 멈췄는지 확인해 우리 기여를 대비 |

## 📖 1차로 충분 (2차 불필요 — 배경·기준선 인용)

| 논문 | 가져다 쓰는 것 |
| --- | --- |
| **TRIAGE** (arXiv 2508.18439, 2026) | 예측-실측 대조 틀. CVE 대상이라 대상이 다름만 명시 |
| **WhatsApp 30억 계정 열거** (arXiv 2511.20252, 2026) | 규모 실측이 가능함(단 비침투 아님)이라는 사실 한 줄 |
| **Breach Risk Magnitude** (AMIA 2016) | 로그 스케일 규모 반영 공식 |
| **Vavilis et al. Anomaly Framework** (C&S 2015) | E×심각도 구조 근거 한 줄 |
| **Bugcrowd VRT** | 평가 기준선(공개 등급표, 원문이랄 게 없음) |
| **Credit Karma** (USENIX Sec 2023) | 비침투 검증 설계 개념 |

## 2차 정독 우선순위 (다음 주 액션)
1. **L-Severity** — 블랙박스 API 적용을 위한 공식 재확인 (점수 설계에 직접 필요)
1. **Uniqueness ratio** — 예측→대조 평가 설계 참고
1. **M-Score** — 식별성 정의 비교
1. **SMS URL 연구** — 우리가 채우는 빈칸의 정확한 경계 확인

## 서지정보 재확인 (노션 확정 전)

최신 arXiv 번호·저자는 원문에서 한 번 더 대조: 2601.09232, 2511.20252, 2607.20574, 2601.11550, 2508.18439, 2608.24957. 특히 SMS URL 연구는 검색에서 저자명이 안 잡혀 제목만 확보.
