# A Non-Intrusive Traffic Analysis Framework for Authorization Risk Detection and Coordinated Response in Web Application

## 논문 정보

## 핵심 키워드
### 보안 개념
- **웹 애플리케이션 보안**: 웹 기반 시스템의 접근 제어 및 권한 검증 강화
- **권한 위험 탐지**: 접근 권한 위반의 가능성을 사전에 식별하고 평가
### 기술적 접근
- **객체 수준 권한 위반**: 사용자가 유효한 세션을 보유하더라도 대상 객체에 접근할 권한이 없을 수 있는 문제
- **비침입적 트래픽 분석**: 애플리케이션의 업무 코드나 내부 권한 로직을 수정하지 않고 프록시·게이트웨이 등에서 요청·응답을 분석하는 접근
### 탐지 및 판단
- **런타임 증거**: 객체 접근 이력, 사용자 신원 일관성, 행동 이상, 인증 맥락, 네트워크 환경, 엔드포인트 작업 위험을 포함하는 판단 근거
- **위험 융합 및 고위험 우선 제약**: 여러 위험 요소를 결합하고, 심각한 증거가 낮은 점수에 묻히지 않도록 우선 판단하는 방식
### 대응 및 운영
- **연동 대응**: 위험 수준에 따라 허용, 경고·관찰, 차단 또는 외부 정책 집행점 연동을 수행
### 평가 범위
- **통제된 테스트베드 평가**: 프레임워크 수준의 작동 가능성을 검증했으며, 생산 환경 전반에 대한 일반화는 아직 입증되지 않

## 한 줄 요약
웹 애플리케이션 코드를 수정하지 않고 요청·응답 트래픽의 객체 접근 증거와 사용자·행동 맥락을 결합해 권한 위험을 탐지하고 단계별 대응을 수행하는 프레임워크를 제안하며, 통제된 테스트 환경에서 그 작동 가능성을 보였다.

## 3줄 요약
- 본 연구는 Web 애플리케이션의 합법 세션 내에서 발생하는 비인가 접근을 탐지하기 위해, 소스 코드 수정 없이 실시간으로 트래픽의 실행 컨텍스트를 분석하는 비침입형 프레임워크를 제안합니다.
- 제안된 프레임워크는 요청-응답 트랜잭션을 기반으로 다양한 런타임 증거를 통합하고, 가중치 융합 및 고위험 우선순위 제약 조건을 통해 위협을 정교하게 판단하며 차단 및 경고 등의 대응을 수행합니다.
- 실험 결과, 제안된 기법은 99.90%의 높은 F1 스코어를 달성하여 기존 규칙 기반 방식보다 우수한 탐지 성능을 보였으며, 단일 호스트 환경에서 낮은 지연 시간으로 실시간 보안 결정이 가능함을 입증했습니다.

## 간략히 보기
### 요약
본 논문은 Web Application 및 API 환경에서 발생하는 객체 수준의 권한 부여 위반(Authorization Violations, 예: BOLA/IDOR)을 실시간으로 탐지하고 대응하기 위한 비침습적(Non-Intrusive) 트래픽 분석 프레임워크를 제안합니다.

### 핵심 방법론 및 기술적 상세
본 프레임워크는 애플리케이션의 소스 코드나 내부 로직을 수정하지 않고, Reverse Proxy나 API Gateway 레벨에서 획득한 트래픽을 분석하여 보안 결정을 내립니다.
#### 1. Transaction Correlation 및 컨텍스트 추출
- HTTP 요청과 응답을 상호 연관(Correlation)시켜 하나의 비즈니스 트랜잭션 $T$를 구성합니다.
- 요청 헤더, 쿠키, JWT, JSON 본문 등에서 UserKey, EndpointKey, ObjectId를 추출하여 사용자의 행동 맥락을 복원합니다.
#### 2. 런타임 권한 위험 증거 추상화
수집된 정보를 6가지 핵심 위험 요소($x$)로 변환하여 정규화($[0, 1]$)합니다:
- $x_{obj}$ — 객체 접근 증거
- $x_{id}$ — ID 일관성
- $x_{beh}$ — 행동 이상
- $x_{auth}$ — 인증 맥락
- $x_{net}$ — 네트워크 환경
- $s_{ep}$ — 엔드포인트 연산 위험

**객체 접근 증거의 정의**:

특정 주체 $u$가 이전의 신뢰할 수 있는 트랜잭션을 통해 접근 권한을 증명했는지 여부를 정의합니다:

$$
E_{u,r}(t) = \{o \mid o \text{ is confirmed for subject } u \text{ by a trusted transaction before } t\}
$$

#### 3. 위험 융합 및 우선순위 제약(Risk Fusion)
단순히 위험 요소를 가중치 합으로 계산하는 것에서 나아가, 고위험 조건이 낮게 평가되는 것을 방지하기 위해 우선순위 제약을 적용합니다:

$$
R_{base} = \min\{1, \max[0, \sum_{i=1}^{6} w_i x_i]\}
$$

$$
R_{total} = \max(R_{base}, \max(\{h_j \mid j \in H\} \cup \{0\}))
$$

여기서:
- $H$는 사전 정의된 고위험 조건 집합
- $h_j$는 특정 위험 상황에서의 하한값

이를 통해 "객체 증거는 없으나 민감한 작업을 수행하는 경우" 등 치명적인 위반 사항을 즉각적으로 식별합니다.

### 실험 결과 및 결론
#### 성능
2,000개의 테스트 샘플(정상 1,000, 공격 1,000)을 대상으로 테스트한 결과:
- **Accuracy**: 99.90%
- **F1 Score**: 99.90%
#### 메커니즘별 중요성 (Ablation Study)
- 객체 접근 증거 제거 시 F1 Score: **81.31%**로 급감
- 고위험 우선순위 제약 제거 시 F1 Score: **73.90%**로 급감

→ 각 메커니즘의 중요성을 입증
#### 실용성
단일 호스트 테스트 환경에서 **P99 Latency 0.137ms** 수준의 낮은 오버헤드로 온라인 처리가 가능함을 확인했습니다.

### 결론 및 시사점
본 논문은 Web Application의 비즈니스 의미론에 기반한 권한 부여 위반을 트래픽 단에서 효과적으로 방어할 수 있는 계층적 구조를 제시하며, 이는 특히 **Zero Trust Architecture** 환경에서의 보완적 보안 메커니즘으로 활용될 수 있습니다.
