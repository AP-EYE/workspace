# 읽기 탐지 테스트 자료 선정 결과

우리 도구가 다른 사람의 비공개 정보를 잘 찾아내고, 정상적으로 공개된 정보를 잘못 신고하지 않는지 확인하기 위해 테스트 자료를 골랐다.

자료의 설명만 읽는 데서 끝내지 않고, 앱을 직접 실행해 실제 응답을 확인했다.

## 무엇을 쓰기로 했나

| 자료 | 사용 목적 | 선택 이유 |
|---|---|---|
| wger | 실제 앱에서 탐지 성능 확인 | 다른 사람의 정보가 노출되는 버전과 문제가 수정된 버전을 비교할 수 있다. |
| Memos | 실제 앱에서 탐지 성능 확인 | 공개 정보, 회원에게 공개된 정보, 비공개 정보를 구분해서 테스트할 수 있다. |
| VAmPI | 개발 중 기능 점검 | 문제가 있는 경우와 정상적으로 차단되는 경우를 간단하게 확인할 수 있다. |

실제 앱 평가는 wger와 Memos로 진행하고, VAmPI는 개발 중 기능을 점검하는 데 사용한다.

## 직접 확인한 결과

### wger

운동과 식단을 관리하는 앱이다.

다른 사람의 식단 정보와 운동 설정이 노출되는 버전, 문제가 수정된 버전을 비교했다.

- 문제가 있는 버전에서는 다른 사람의 정보가 반환됐다.
- 수정된 버전에서는 다른 사람의 정보를 차단하거나 목록에서 제외했다.
- 자신의 정보는 정상적으로 조회됐다.
- 로그인하지 않거나 잘못된 인증 정보를 사용한 경우도 확인했다.

총 80번 조회했다. 이 중 식사항목 조회는 앱 자체에서 오류가 발생해 해당 경로의 20개 결과를 모두 제외했다. 나머지 60개를 평가 자료로 사용한다.

별도로 공개 운동 계획을 다른 사람이 정상적으로 조회할 수 있는지 확인하는 원본 테스트 8개도 통과했다.

### Memos

메모를 작성하고 공개 범위를 정하는 앱이다. BACScan 논문에서 사용한 앱 중 하나다.

총 36번 조회해 다음을 확인했다.

- 공개 메모는 로그인하지 않아도 볼 수 있었다.
- 회원 공개 메모는 로그인한 다른 회원도 볼 수 있었다.
- 비공개 메모는 작성자만 상세 조회할 수 있었다.
- 그런데 목록 조회 조건을 바꾸면, 상세 조회에서 차단된 비공개 메모가 목록에 나타났다.

같은 메모의 상세 조회와 목록 조회를 비교했기 때문에, 단순히 응답이 성공했다는 이유로 정보 노출이라고 판단한 것은 아니다.

### VAmPI

API 취약점을 연습하도록 만든 앱이다.

실제 로그인 후 총 40번 조회했다.

- 문제가 있는 모드에서는 다른 사람의 책에 담긴 비공개 내용이 반환됐다.
- 수정된 모드에서는 같은 조회가 차단됐다.
- 공개 책 목록에는 비공개 내용이 포함되지 않았다.
- 로그인하지 않은 경우, 잘못된 인증 정보, 존재하지 않는 책도 확인했다.

기능 점검에는 유용하지만, 실제 서비스에서의 성능을 보여주는 자료와는 구분한다.

## 이번에 쓰지 않는 자료

- **BACScan의 나머지 사례:** 논문에 나온 사례를 모두 직접 재현한 것은 아니다. 이번에는 확인을 마친 Memos 사례만 사용한다.
- **BolaZ:** 논문에서 사용한 정확한 앱 버전과 테스트 정답을 확보하지 못했다. 코드 확인까지 진행했으며, 이번 평가에서는 제외한다.

## 최종 정리

- 실제 앱 평가: wger와 Memos, 총 96개 조회 사례
- 개발 중 기능 점검: VAmPI, 총 40개 조회 사례

같은 문제를 여러 계정이나 조건으로 반복 확인한 결과가 포함되어 있다. 조회 횟수를 서로 다른 취약점의 개수로 세지 않는다.

이번 작업은 테스트에 사용할 자료와 정답을 확인한 것이다. 아직 Akto나 우리 도구의 탐지 성능을 측정한 결과는 아니다.

이제 이 자료를 고정하고, 같은 조건에서 Akto와 우리 도구의 결과를 비교한다.
