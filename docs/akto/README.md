## 조사 체크리스트

체크는 조사·기록 완료를 뜻한다. 미확인 사항을 확인된 것으로 처리하지 않는다.

- [x] 관리 상태: 최근 커밋·릴리스 확인. 현재 평균 이슈·PR 응답 속도는 미확인, 과거 단일 사례와 구분.
- [x] 커뮤니티: 스타·기여 계정 수·과거 커뮤니티 PR 머지 확인. 봇 포함 계정 수를 사람 수로 해석하지 않음.
- [x] BOLA 관련 이슈: 관련 이슈·PR 조사. 회의에서 언급한 2023~2024 결함 이슈 링크는 찾지 못해 추가 확인 필요.
- [x] 한국 특화: 국내 전화번호·한국어 사용자 정의 정규식 분리 실행. UI·전체 runtime 미실행.
- [x] AI 기능: AktoGPT·agentic 기능 존재 확인. 한국어 법적 분류 성능은 미확인.
- [x] 기여 지점과 결정: URL private 컨텍스트 정보 손실을 우선 재현하고 기여 검토.

**결정: 기여 우선.** 한국어 유형은 기존 설정부터 평가하고 코드 결함 후보는 DB·서버 회귀 테스트를 거친 뒤 업스트림 제안을 검토한다. fork는 필요한 변경의 수용이 어려울 때 검토한다. 이번 조사는 제품 전체 실행이나 성능 평가 완료를 뜻하지 않는다.
